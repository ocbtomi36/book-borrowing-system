# Car Rental Management API


## 1. About the project

This is a node.js and express based REST API that serves as the backend for a book borrowing system.

---


## 2. Used Technologies

 * Node.js
 * Express.js
 * Sequelize
 * MySQL
 * JWT
 * Git

## 3. Contributors

This is an independently developed project. 

## 4. Features

 * User authentication with login and registration
 * CRUD operations for each entity

## 5. Necessary Environment Variables
    PORT
    HOST    
    USER
    PASSWORD
    DATABASE
    JWT_PASSWORD

## 6. Getting Started 

### 6.1 Prerequisites

 * Node.js version 17 or higher
 * MySQL Server 8.0+ or MariaDB 10.5+
 * MySQL Workbench 8.0 CE (recommended graphical client)
 * Git or another Git-compatible version control tool

### 6.2 How to get the project

1. Clone the repository on your local machine

```bash
HTTPS: https://github.com/ocbtomi36/book-borrowing-system.git
```
or 
```bash
GitHub_CLI: gh repo clone ocbtomi36/book-borrowing-system
```

2. Open the project terminal and run: 

```bash
    npm install
```
With that command you install all necessary packages.

### 6.3 Start the project

1. Create an ` .env ` file and use the variables names. List you can find section 5.

2. To run the program

Go to your project terminal and run command:

```bash
    npm start
```

By the first run this program creates a database. You need to create a user with password and use this project.
